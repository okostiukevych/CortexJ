CortexJ Maven Repository

Static Maven repository for CortexJ — portable AI execution for the JVM.

Use it

<repositories>
    <repository>
        <id>cortexj</id>
        <url>https://okostiukevych.github.io/CortexJ-maven/</url>
    </repository>
</repositories>

<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>io.cortexj</groupId>
            <artifactId>cortexj-bom</artifactId>
            <version>1.0.0-RC1</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

<dependency>
    <groupId>io.cortexj</groupId>
    <artifactId>cortexj-starter-java21</artifactId>
</dependency>

What is published

Version 1.0.0-RC1: 77 modules (starters for Java 8, 11, 17, 21, 25; core, repositories, runtimes, Spring Boot starter, CLI and more), each with binary, -sources and -javadoc jars plus maven-metadata.xml and .sha1/.md5 checksums. Java packages remain io.cortexj.* — only the repository URL differs from a Maven Central install.

Until Central

CortexJ is not yet on Maven Central: the io.cortexj namespace needs a domain the maintainer does not own. This repository and JitPack (com.github.okostiukevych.CortexJ, version named explicitly) serve the same build in the meantime.
