- [ ] FAQ section after Quick start:

```html
  <section id="faq">
    <div class="container">
      <p class="label">FAQ</p>
      <h2 class="section-title">Frequently asked, honestly answered</h2>
      <div class="faq">
        <details class="faq-item">
          <summary>Which Java versions are supported?</summary>
          <p>All LTS lines — Java 8, 11, 17, 21 and 25 — through dedicated starters. Business code is identical across them; a starter/JVM mismatch fails fast with an actionable diagnostic (<code>CORTEXJ-CONF-0002</code>).</p>
        </details>
        <details class="faq-item">
          <summary>Do I need Python?</summary>
          <p>No. CortexJ is JVM-only. For local GGUF text generation you point the llama.cpp provider at a <code>llama-server</code> binary; ONNX embeddings run on the bundled ONNX Runtime (CPU).</p>
        </details>
        <details class="faq-item">
          <summary>Is GPU supported?</summary>
          <p>Honestly: the llama.cpp provider plans GGUF for CPU and GPU; the bundled ONNX Runtime ships the CPU execution provider only. Hardware is probed, never assumed — unusable candidates are rejected with reasons in the plan, not at runtime.</p>
        </details>
        <details class="faq-item">
          <summary>How is this different from Spring AI or LangChain4j?</summary>
          <p>Those are application frameworks; CortexJ is the runtime layer underneath. It resolves models, plans execution and manages runtimes — and ships adapters that expose CortexJ models as Spring AI / LangChain4j <code>ChatModel</code>, <code>StreamingChatModel</code> and <code>EmbeddingModel</code> implementations, so your framework-side code stays unchanged.</p>
        </details>
        <details class="faq-item">
          <summary>When will it be on Maven Central?</summary>
          <p>Before a public 1.0: Maven Central publishing, the API stability freeze process and a signed-off production security review are the remaining gates. Until then the platform is <code>0.1.0-SNAPSHOT</code>, documented exactly as it exists.</p>
        </details>
      </div>
    </div>
  </section>
```

<script>
(function () {
  document.querySelectorAll(".code-card").forEach(function (card) {
    var btn = card.querySelector(".copy-btn");
    if (!btn) return;
    btn.addEventListener("click", function () {
      navigator.clipboard.writeText(card.querySelector("pre").innerText).then(function () {
        btn.textContent = "Copied";
        setTimeout(function () { btn.textContent = "Copy"; }, 1500);
      });
    });
  });
  var starter = document.getElementById("starter-artifact");
  if (starter) {
    document.querySelectorAll(".tab").forEach(function (tab) {
      tab.addEventListener("click", function () {
        document.querySelectorAll(".tab").forEach(function (t) { t.classList.remove("active"); });
        tab.classList.add("active");
        starter.textContent = "cortexj-starter-" + tab.dataset.starter;
      });
    });
  }
})();
</script>
